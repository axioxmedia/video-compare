# 视频差异比对工具

纯本地 HTML 工程，无需服务器、无需安装。基础差异分析零下载、零外部依赖，双击 `index.html` 即可运行。另有默认关闭的「AI 进阶分析」，可选本地模型或云端 API。

## 核心能力

围绕「比较两个视频的差异性」构建，全部为真实计算：

1. **技术参数解析**：分辨率、长宽比、精确帧率、总帧数、时长、编码、码率、帧率模式（mp4box 纯 JS 解析，mediainfo WASM 在 http 模式下兜底）。两侧参数一致标绿、不一致标红。
2. **时间轴对齐**：两个视频按归一化进度抽取相同数量的对应帧，时长、帧率不同也能一一对应；帧统一缩放到分析尺寸，contain 留黑边不拉伸。
3. **逐帧像素差异**：对每对帧计算 MAE、MSE、RMSE、PSNR、RGB 分通道误差、差异像素占比。
4. **差异热力图**：把差异区域在画面上高亮，精确定位局部修改（水印、贴片、角标、局部特效等）的位置。
5. **时间轴差异曲线**：纵轴自适应量程，标注差异峰值时间点，判断差异是集中在某一段还是贯穿全片。
6. **综合相似度与等级**：0–100 相似度，分为基本一致 / 轻微差异 / 明显差异 / 显著差异 / 内容不同，并自动生成差异原因分析与处置建议。
7. **AI 进阶分析（默认关闭）**：见下。

## AI 进阶分析

默认关闭，在「设定」中手动开启，提供两种后端：

### 本地模型（MoveNet，离线）

- 基于 TensorFlow.js MoveNet 单人体模型，输出 17 个 COCO 关键点（鼻、眼、耳、肩、肘、腕、髋、膝、踝），可识别手臂位置、肘关节角度、整体骨架与动作同步性。
- 点击「下载 / 更新本地模型」后流式下载，进度条实时显示百分比、当前文件与已下载大小；下载完成自动存入浏览器 IndexedDB，并在已授权项目文件夹时自动写入该文件夹的 `ai-models` 子目录。
- 提供 Lightning（192，快，约 4.7MB）与 Thunder（256，高精度）两个变体。
- 「下次开启自动加载模型」开关决定重开页面时是否自动加载；运行时模型从 IndexedDB 读取，file:// 下也能离线推理，不依赖网络。
- 报告含手臂位置等级、手腕/肘/肩位移、肘关节角度差、A/B 骨架与叠加对比图、逐关键点位移表；画面无可靠人体时自动降级提示，不编造结果。

### 云端 API（API Key）

- 兼容 OpenAI 多模态视觉接口，可自定义接口地址（Base URL）、API Key、模型名，把代表帧发送到云端，返回手臂位置、肢体差异、场景物体、关键发现与建议的结构化结果。
- 支持「测试连接」，带超时与 HTTP 错误提示。API Key 仅保存在本地 IndexedDB，请求直接发往所配置的服务。

### 项目文件夹

- 在 Chromium 内核浏览器（Chrome / Edge）中可「授权项目文件夹」，模型下载后自动写入该文件夹；不支持 File System Access 的浏览器自动降级为 IndexedDB 缓存，离线运行不受影响。

## 使用

- 直接双击 `index.html`（推荐 Chrome / Edge），分别加载视频 A、视频 B，点击「开始差异分析」。
- 也可用本地服务器打开：`python3 -m http.server` 后访问对应地址。
- 在「设定」中调整采样帧数、分析分辨率、差异判定阈值、热力图配色、是否自动恢复，以及 AI 进阶分析。

## 指标含义

- **MAE（平均绝对误差）**：0–255，越小越接近。
- **MSE / RMSE**：像素差平方的均值及其平方根，放大大差异。
- **PSNR（峰值信噪比）**：单位 dB，越高越接近；完全相同为 ∞。一般 >40 dB 视为内容一致、仅压缩差异，30–40 dB 有可感知差异，<30 dB 差异明显。
- **差异像素占比**：灰度差超过阈值的像素比例，配合热力图判断改动范围。
- **综合相似度**：整体帧差与差异占比的加权得分，0–100。
- **姿态位移**：关键点归一化坐标差（×100% 显示），跨分辨率可比；手腕位移越小代表手臂位置越接近。

## 数据保存与隐私

- 视频 Blob、抽帧、参数、分析结果与本地 AI 模型通过浏览器 IndexedDB 自动保存，重新打开页面自动恢复，并显示恢复提示；可随时点击「清空会话」删除全部本地数据。
- 若浏览器不支持 IndexedDB 或存储空间不足，会自动降级为内存模式，本页分析不受影响，但刷新后不保留，界面会明确提示。
- 基础分析与本地 AI 模式全程无网络请求，视频与结果不离开本机。
- 仅当主动选择云端 API 模式并运行时，才会把所选代表帧发送到你配置的接口地址；请在确认该服务可信后使用。

## 技术说明

- 无构建步骤，普通 `<script>` 标签加载，file:// 友好；AI 模型通过自定义 IOHandler 从 IndexedDB 加载，规避 file:// 下 fetch 模型文件的限制。
- 无 WebGL 环境时 TensorFlow.js 自动回退 CPU 后端（速度较慢，逻辑一致）；常规设备使用 WebGL 加速。
